# 抖音信息提取器 (Douyin User Info Extractor) v10.3

## 项目简介
抖音信息提取器是一款功能强大的浏览器用户脚本，能够智能识别抖音主页类型，自动获取并展示博主昵称、SecUID、UID、SecUserID等关键信息，并提供便捷的一键复制功能。脚本采用现代化UI设计，操作流畅，界面美观。

> **注意**：由于浏览器安全限制，完整的Cookie信息需要手动通过开发者工具获取。另外，**获取自己的 SecUserID 需要手动点击「关注列表」按钮**，脚本会通过监听网络请求自动提取。

## 功能特性
- 🔍 **智能识别**：自动区分"自己主页"与"他人主页"，采用不同配色方案
- 📊 **数据提取**：实时提取博主昵称、SecUID、UID、SecUserID等关键信息
- 📋 **一键复制**：支持单个信息复制或全部信息一键导出
- 🎨 **精美界面**：现代化渐变UI设计，悬浮按钮，响应式布局
- ⚡ **自动获取**：通过监听网络请求智能获取用户信息（自己主页需先点击「关注列表」触发）
- 📱 **移动适配**：完美适配桌面端和移动端浏览器

## 安装使用

### 前提条件
本脚本需要配合浏览器扩展程序「篡改猴 (Tampermonkey)」使用。

**安装步骤：**
1. 首先安装 [Tampermonkey 扩展](https://www.tampermonkey.net/)
2. 点击脚本链接导入到 Tampermonkey 中
3. 启用脚本后访问抖音网页版即可使用

### 使用说明
1. **打开抖音网页版**：访问 https://www.douyin.com/
2. **浏览用户主页**：访问任意用户主页或自己的主页
3. **触发信息获取**：
   - 在**他人主页**：向下滚动作品列表，脚本会自动从网络请求中提取博主信息。
   - 在**自己主页**：需要手动点击页面上方的「关注列表」按钮（或「关注」按钮），脚本会立即捕获请求并提取您的 SecUserID。
4. **点击悬浮按钮**：页面右下角会出现悬浮按钮，点击即可打开信息面板查看已提取的信息。
5. **一键复制**：点击对应按钮即可复制信息。

### Cookie获取指引
如需获取完整Cookie用于其他工具（如 dysync.net），请按以下步骤操作：

1. **登录并进入个人主页**  
   打开抖音网页版 (https://www.douyin.com/) 并登录您的账号，然后进入您的个人主页。

2. **打开开发者工具**  
   按下 **F12** 键（或右键 → 检查），切换到「Network（网络）」标签。

3. **筛选关注列表请求**  
   在Network筛选框中输入 **/follow**（或 **list?**），以便快速定位。

4. **触发关注列表加载**  
   点击您头像旁边的「关注」按钮，弹出关注列表。此时Network中会出现相关请求。

5. **找到目标请求**  
   在请求列表中找到名称包含 **list/?device_platform=webapp** 的请求（通常为 `following/list`），点击它。

6. **复制完整Cookie**  
   在右侧「Headers（标头）」中，向下滚动找到 **Cookie** 字段，**完整复制整个值**（注意不要带换行符，确保完整复制所有内容）。  
   > 小技巧：右键点击Cookie值 → 选择「复制值」可避免多余字符。

7. **（可选）查看SecUserID**  
   在该请求的URL中，您可以看到 **sec_user_id** 参数，其值即为您的SecUserID（脚本已自动获取，无需手动复制）。

> **重要提示**：
> - Cookie 包含您的登录凭证，请勿分享给他人。
> - 每次登录后Cookie会变化，需要重新获取。
> - 复制时请确保没有多余空格或换行，否则可能导致工具验证失败。

## 技术细节

### 版本信息
- **当前版本**：v10.3
- **更新日期**：2026年3月
- **主要变更**：修复 SecUserID 提取路径（从 `data.user.sec_uid` 获取），更新 Cookie 获取指引为更准确的操作步骤（基于关注列表请求）。

### 工作原理
1. **网络请求监听**：通过重写XMLHttpRequest和Fetch API监听抖音数据请求
2. **数据解析**：从API响应中提取用户信息
   - 他人主页：从作品列表接口（`/web/aweme/post`）响应中提取博主昵称、UID、SecUID
   - 自己主页：从关注列表接口（`/web/user/following/list`）响应中提取当前登录用户的 SecUserID（字段 `data.user.sec_uid`）
3. **智能识别**：根据URL和页面特征判断主页类型
4. **自动触发**：在自己主页，脚本会尝试自动点击「关注列表」按钮（若未成功则提示手动点击）

### 兼容性
- **浏览器**：Chrome, Firefox, Edge等现代浏览器
- **用户脚本管理器**：Tampermonkey, Violentmonkey
- **平台**：Windows, macOS, Linux, Android, iOS
